# Definition of Done

Версия считается завершенной, если:

- приложение запускается через Docker;
- пользователь может зарегистрироваться;
- пользователь может войти в систему;
- работают роли;
- база данных имеет миграции;
- проект имеет документацию;
- основные проверки выполняются автоматически.

# Guiding Principles

Перед добавлением новой функции необходимо ответить:

- Решает ли она реальную проблему?
- Делает ли систему лучше?
- Не усложняет ли архитектуру без необходимости?
- Нужна ли эта технология прямо сейчас?
- Помогает ли она развитию инженерных навыков?

Если функция не отвечает этим критериям, она остается в Future Ideas.

# Long-term Vision

Через несколько лет NodeCore должен стать полноценной платформой управления Linux-инфраструктурой.

Главная ценность проекта — не количество функций, а качество архитектуры, инженерных решений и процесса разработки.
